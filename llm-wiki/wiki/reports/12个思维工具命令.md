## 一句话摘要

Internet Vin 开发的一套自定义 Claude Code slash 命令，将 Claude 从通用助手变成深度个性化思维伙伴，基于 Obsidian vault 中的个人笔记实现思想追踪、模式发现和信念压力测试。

## 核心观点

### 关键前提

1. **Obsidian CLI** 让 Claude Code 不只能读文件，还能看到文件之间的链接关系
2. **写作是燃料**：vault 里积累的笔记越多，这些命令能做的事就越强大
3. **人写 vs AI 写严格分离**：保持 vault 中哪些是自己写的、哪些是 AI 生成的界限

### 12 个命令（部分收录）

| 命令 | 类别 | 功能 |
|------|------|------|
| `/context` | 日常操作 | 加载全量上下文：读取 vault，汇总当前项目、近期反思、过去 7 天优先事项 |
| `/today` | 日常操作 | 晨间规划：拉取日历、任务、日记，生成当天优先行动计划 |
| `/closeday` | 日常操作 | 日终复盘：总结进展，捕捉新想法，记录未完成事项 |

> 注：原始文档仅完整收录了前 3 个命令，剩余 9 个命令需查看飞书原文。

### 英文版 Prompt 示例

```
/context: Read my vault and summarize my current context. Include active projects, recent reflections, and any priorities I've mentioned in the last 7 days.
/today: Read my daily note, calendar, and task list. Generate a prioritized plan for today based on what I've said is important this week.
```
