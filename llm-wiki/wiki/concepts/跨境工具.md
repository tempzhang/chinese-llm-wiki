# 🌍 跨境工具

跨境电商和出海业务从选品到收款的实用工具链。

## 选品与调研

- **AdSpy / PowerAdSpy** — Facebook 广告素材监测
- **BigSpy** — 多平台广告搜索
- **Diffshop（店湖）** — Shopify/Shein/TikTok 多平台选品
- **Ecomhunt** — 爆款产品发现
- **Jungle Scout / Helium 10** — Amazon 选品
- **Etsyshop / Sale Samurai** — Etsy 选品分析

## 独立站搭建

- **Shopify** — 全球最大 SaaS 独立站
- **OpenCart** — 开源电商系统
- **WooCommerce** — WordPress 电商插件
- **竹子建站 / 跨屏网** — 零代码建站

## 一件代发（Dropshipping）

- **CJdropshipping** — 全球一件代发
- **Zendrop** — Shopify 专用 Dropshipping
- **Oberlo** — Shopify 官方代发

## 支付方案

- **Stripe** — 独立站首选信用卡收款
- **PayPal** — 全球买家最熟悉的支付方式
- **PingPong / Airwallex** — 跨境收款提现
- **AB 跳转方案** — FP 独立站轮询支付

## 地址与合规

- **美国地址生成器** — 注册美区服务辅助
- **Anytime Mailbox** — 虚拟美国地址
- **ITIN/EIN 申请** — 美国税务身份
