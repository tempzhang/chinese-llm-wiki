# 🌐 OpenWRT 与软路由

OpenWRT 是 Linux 路由器操作系统，软路由是 DIY 网络设备的核心玩法。

## 一句话定义

OpenWRT 是开源的嵌入式 Linux 系统，让普通路由器变身可编程网络网关。

## 主流固件

- **OpenWRT 官方** — 原版开源固件
- **ImmortalWrt** — 国内用户优化版
- **iStoreOS** — 带应用商店的易用固件
- **Kwrt** — 在线定制编译

## 核心插件

- **OpenClash** — 代理分流客户端，支持链式代理和多 WiFi 隔离
- **PassWall** — 轻量代理插件
- **AdGuard Home** — DNS 去广告 + 防污染
- **HomeProxy** — 基于 Sing-box 的新一代代理

## 硬件推荐

- **R5S** — 入门软路由首选
- **红米 AX6000** — 刷机热门机型，支持多 WiFi 链式代理
- **Cudy TR3000** — AX3000 方案
- **玩客云 / N1 盒子** — 20 元入门方案
- **磊科 N60 Pro** — 2GB 内存高性价比

## 跨境电商应用

- 多 WiFi + 链式代理 → 一设备一 IP 隔离
- DNS 防泄漏 + WebRTC 防泄漏
- 指纹浏览器 + 软路由方案
