# 🐋 DeepSeek

DeepSeek（深度求索）是国产开源大语言模型，以高性价比和透明技术路线著称。

## 一句话定义

DeepSeek 是中国团队打造的开源大模型系列，性能对标 GPT-4 级别，API 价格仅为同类的十分之一。

## 核心特点

- **开源透明**：完整公开模型权重和技术报告
- **极致性价比**：API 调用成本远低于 OpenAI/Anthropic
- **中文优化**：中文理解和生成能力天然优势
- **本地部署**：支持 Ollama 等工具一键本地运行

## 主要产品

- **DeepSeek Chat** — Web 端对话应用
- **DeepSeek API** — 开发者接口，兼容 OpenAI API 格式
- **开放平台** — API Key 管理、用量监控

## 与 Codex 集成

DeepSeek 可作为 Codex CLI 的后端模型，替代默认模型进行本地编程辅助。通过配置 API endpoint 即可接入，大幅降低使用成本。

## 与 Claude Code 集成

国内用户可通过 DeepSeek API 作为 Claude Code 的后端，绕过网络限制免费使用 AI 编程能力。

## 与其他模型关系

- 与 ChatGPT、Claude、Grok 等并列主流大语言模型，参见 [[AI工具]]
- API 可通过 OpenRouter 等聚合平台统一调用
