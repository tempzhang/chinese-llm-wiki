# 🛠 AI工具

常用 AI 工具清单，覆盖大语言模型、API 聚合、AI 搜索、图像/音乐生成。

## 大语言模型

- **ChatGPT** — OpenAI 旗舰对话模型
- **Claude** — Anthropic 出品，以长上下文和安全性见长
- **Grok** — xAI（马斯克）旗下，深度整合 X/Twitter
- **DeepSeek** — 国产开源大语言模型，性价比突出
- **豆包** — 字节跳动 AI 助手

## API 聚合平台

- **OpenRouter** — 多模型 API 聚合，统一计费
- **Google AI Studio** — Google Gemini API 免费额度

## AI 搜索

- **Perplexity** — AI 搜索引擎，实时联网

## 图像生成

- **Civitai** — Stable Diffusion 模型社区，海量 LoRA/Checkpoint

## 音乐生成

- **Suno** — AI 音乐创作，文本→歌曲

## 笔记与知识管理

- **NotebookLM** — Google AI 笔记助手
- **Obsidian** — 本地 Markdown 知识库，社区插件生态丰富
