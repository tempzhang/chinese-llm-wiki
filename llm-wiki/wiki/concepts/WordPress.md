# 📝 WordPress

WordPress 是全球使用最广泛的内容管理系统（CMS），占据全球网站约 43% 的份额。

## 一句话定义

WordPress 是开源 CMS，从个人博客到企业官网到电商独立站，都能一站搭建。

## 核心生态

- **主题（Theme）**：决定网站外观，有免费和付费主题市场
- **插件（Plugin）**：扩展功能，6 万+ 插件覆盖 SEO、安全、电商、缓存等
- **WooCommerce**：WordPress 官方电商插件，把网站变成在线商店

## 建站要素

- **域名** — NameSilo、GNAME 注册
- **主机** — SiteGround、CloudPanel 面板
- **SSL** — Cloudflare 免费 CDN + HTTPS
- **SEO** — Rank Math / Yoast SEO 插件
- **缓存** — WP Rocket / W3 Total Cache

## 跨境电商场景

搭配 WooCommerce + 支付网关 + 物流插件，即可搭建独立站。配合 [[SEO工具]] 和 [[自动SEO]] 流程提升自然流量。
