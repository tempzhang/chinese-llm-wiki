# 🖥 NAS 与自建服务

NAS（网络附加存储）是个人/小团队自建数字基础设施的核心。

## 一句话定义

NAS 是一台 24 小时运行的家庭服务器，集文件存储、媒体中心、Docker 应用、智能家居中枢于一身。

## 核心用途

- **文件存储** — 私人云盘，替代百度网盘/iCloud
- **媒体中心** — Plex/Jellyfin/Emby 搭建家庭影音库
- **Docker 应用** — 运行 200+ 自托管服务
- **下载器** — qBittorrent/Transmission/Deluge 离线下载
- **智能家居** — Home Assistant 中控

## 常用自建服务

- **Jellyfin / Plex** — 影视媒体库
- **Jellyseerr** — 影视请求 + 自动下载联动
- **Nastools** — 影音自动化套件
- **AList** — 多网盘统一管理
- **OpenWRT** — 软路由系统
- **Home Assistant** — 智能家居平台

## Docker 生态

几乎所有自建服务都通过 Docker 部署：
- **Portainer** — Docker 可视化管理
- **Docker Compose** — 多容器编排

## 硬件选择

- 成品 NAS：群晖 / 威联通 / 绿联
- DIY NAS：旧电脑 / N100 小主机 / 树莓派
- 云手机服务器：RK3588 方案（魔云腾）
