# 示例资料摘要

## 来源

## 一句话摘要

Karpathy 提出使用 LLM 来自动维护一个结构化的个人 Wiki，而不是使用 RAG 实时检索知识。

## 核心观点

- RAG 的"分块 + 检索"方式在深度知识场景下效果不佳
- 更好的方式是让 LLM 先"读懂"资料，写成结构化的 Wiki 页面
- 这样 LLM 在使用时直接读取完整的 Wiki 页面，而不是拼凑碎片
- 每个 Wiki 页面都是人类可读、LLM 可理解的
- 使用 Markdown + Git 作为存储和版本控制方式

## 关键引用
