# 🏗 建站

网站建设相关技术栈、工具和平台。

## CMS 内容管理系统

- **WordPress** — 全球最流行的 CMS，生态最丰富
- **WooCommerce** — WordPress 电商插件
- **OpenCart** — 轻量级开源电商系统
- **DedeCMS / 织梦** — 国产老牌 CMS
- **PbootCMS** — 国产轻量企业建站系统
- **帝国 CMS** — 大型门户网站常用

## 域名与服务器

- **NameSilo** — 低价域名注册 + 免费隐私保护
- **GNAME** — 域名注册
- **聚名网** — 老域名买卖、到期抢注
- **CloudPanel / HestiaCP** — 开源服务器面板（宝塔替代）
- **野草云 / Megalayer / 莱卡云** — 香港 CN2 优化线路

## 建站辅助

- **小蚂蚁资源网 / 枫创资源站** — 网站模板下载
- **竹子建站 / 跨屏网** — SaaS 自助建站
- **FastAdmin / ThinkPHP** — PHP 开发框架
