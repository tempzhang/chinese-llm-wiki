# 中文 LLM Wiki 总览

## 一句话定义

中文 LLM Wiki 是一个面向 AI Agent 维护的、结构化、版本化的中文知识编译系统。

## 核心理念

传统知识管理的问题：
- 笔记碎片化，难以形成体系
- RAG 直接分块检索，丢失上下文
- 人工维护 Wiki 成本高、质量差

LLM Wiki 的解法：
- AI Agent 负责消化原始资料
- 将知识编译为结构化的 Wiki 页面
- Git 版本控制，可审查、可回滚
- 双向链接构成知识网络

## 仓库结构概览

| 层级 | 目录 | 作用 |
|------|------|------|
| 原始资料层 | `raw/` | 存放网页、视频、PDF 等原始资料，不做修改 |
| 知识编译层 | `wiki/` | AI 编译后的结构化页面 |
| 模板层 | `templates/` | 9 种页面模板 |
| 工具层 | `tools/` | 搜索、检查、索引更新等自动化脚本 |
| 提示词层 | `prompts/` | 面向 AI Agent 的维护提示词 |
| 索引层 | `index.md` / `log.md` / `changelog.md` | 知识导航和变更追踪 |
