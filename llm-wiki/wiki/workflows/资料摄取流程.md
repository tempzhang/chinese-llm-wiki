# 资料摄取流程

## 一句话定义

资料摄取流程是将新原始资料（网页、视频、PDF 等）引入 LLM Wiki 并编译为结构化页面的标准操作流程。

## 前置条件

- 新资料已放入 `llm-wiki/raw/` 对应子目录
- AI Agent 已加载 AGENTS.md 规则

## 步骤

### 步骤 1：确认资料位置

检查资料是否已放入正确的 raw 子目录：
- 网页文章 → `raw/sources/`
- 视频笔记 → `raw/videos/`
- PDF 文档 → `raw/pdfs/`
- 截图素材 → `raw/images/`
- 转录文本 → `raw/transcripts/`

### 步骤 2：阅读资料

完整阅读资料内容，了解其主题、核心观点和涉及的领域。

### 步骤 3：搜索现有知识

运行 `python tools/wiki_search.py "<关键词>"` 检查 Wiki 中是否已有相关内容，避免重复。

### 步骤 4：分析需要创建/更新的页面

确定资料涉及的知识类型：
- 新概念 → 创建 `concepts/` 页面
- 新实体 → 创建 `entities/` 页面
- 新流程 → 创建 `workflows/` 页面
- 新问题 → 创建 `questions/` 页面
- 对比观点 → 创建或更新 `comparisons/` 页面
- 深度分析 → 创建 `reports/` 页面

### 步骤 5：创建/更新页面

使用 `templates/` 中的对应模板。

### 步骤 6：交叉链接

在正文中使用 ``[[页面标题]]`` 链接到相关页面。

### 步骤 7：更新索引和日志

- 运行 `python tools/update_index.py`
- 在 `log.md` 中记录操作

### 步骤 8：健康检查

运行 `python tools/wiki_lint.py` 确保没有引入问题。

## 注意事项

- 禁止编造来源
- 没有来源的内容明确标注 `sources: []`
- 不要覆盖已有内容，优先更新而非重建
