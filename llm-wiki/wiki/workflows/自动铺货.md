# 📦 自动铺货

商品自动化上架流程，从采集到 AI 生成到一键发布。

## 流程

1. **采集** — 从 1688、阿里巴巴等货源平台抓取商品数据
2. **AI 生成** — 使用 AI 改写标题、生成描述、翻译多语言、处理图片
3. **发布** — 自动发布到独立站（WordPress/WooCommerce/Shopify）

## 核心工具

### 采集
- **OpenClaw** — 自动化采集阿里巴巴产品，AI 赋能 WordPress 全自动上货
- **八爪鱼采集器** — 通用网页数据采集

### AI 生成
- 用 [[AI工具]] 批量改写商品描述，实现「去 AI 化」深度洗稿
- 搭配 [[AI Agent 框架（Dify / Coze / Hermes / OpenClaw）]] 构建自动化流水线

### 发布
- **WordPress + WooCommerce** — 独立站批量上架
- **CRMEB** — 开源商城系统
- **yshop（意象商城）** — SpringBoot 前后端分离商城

## 一件代发

- **CJdropshipping** — 全球一件代发平台
- **Zendrop** — Shopify 专用
- **Oberlo** — 已整合至 Shopify

## 进阶自动化

- 搭配 [[自动化工具对比（n8n / Zapier / Make / Dify / Coze）]] 编排端到端工作流
- [[Docker 速查]] 部署自托管自动化服务栈
