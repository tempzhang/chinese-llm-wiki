# ⚡ 自动化工具对比

n8n、Zapier、Make、Dify、Coze 五大 AI 自动化/工作流平台横向对比。

## 定位速览

| 工具 | 定位 | 部署方式 | 开源 |
|------|------|----------|------|
| **n8n** | 通用工作流自动化 | 自部署 / 云 | ✅ |
| **Zapier** | 应用间连接器 | 仅云端 | ❌ |
| **Make** | 可视化工作流 | 仅云端 | ❌ |
| **Dify** | AI 应用开发平台 | 自部署 / 云 | ✅ |
| **Coze** | AI Bot 搭建平台 | 仅云端 | ❌ |

## 核心差异

- **n8n**：最灵活，支持 1000+ 集成，代码节点可写自定义逻辑，适合技术团队
- **Zapier**：最简单，即插即用，适合非技术用户，但价格随用量飙升
- **Make**：可视化最强，拖拽式流程设计，介于 Zapier 和 n8n 之间
- **Dify**：专注 AI 应用，内置 RAG、Agent、工作流编排，适合 LLM 应用开发
- **Coze**：字节跳动出品，Bot 商店 + 插件生态，适合快速搭建 AI 对话机器人

## 选型建议

| 场景 | 推荐 |
|------|------|
| 非技术人员快速连接应用 | Zapier |
| 技术团队自建复杂自动化 | n8n |
| 可视化流程 + 中等复杂度 | Make |
| 构建 LLM 驱动的 AI 应用 | Dify |
| 快速搭建 Bot 并发布到多平台 | Coze |
