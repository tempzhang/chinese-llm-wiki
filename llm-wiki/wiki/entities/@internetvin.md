# @internetvin

X/Twitter 用户（Internet Vin），开发了一套自定义 Claude Code slash 命令，基于 Obsidian vault 中的个人笔记，将 Claude 从通用助手变成深度个性化思维伙伴。

## 核心贡献

- **12 个思维工具命令**：/context、/today、/closeday 等，覆盖日常操作、思维演练、信念压力测试
- **Obsidian + AI Agent**：倡导「写作是燃料」理念，AI 理解力随笔记量增长而增强
- **人写 vs AI 写严格分离**：保持 vault 中原始笔记与 AI 生成内容的清晰边界
