# 术语表

> 按拼音排序。持续更新中。

## A

- **AI Agent**：能够自主执行任务的 AI 程序，可读写文件、调用工具、维护知识库。详见 [[AI Agent 知识维护]]。
- **API（应用程序接口）**：Application Programming Interface，软件系统间的通信契约。LLM Wiki 中 API 用于模型调用、工具集成和数据交换。

## C

- **ChatGPT**：OpenAI 的旗舰对话模型，支持多轮对话、代码生成、文件分析等。详见 [[AI工具]]。
- **CLI（命令行界面）**：Command-Line Interface，通过终端文本命令操作软件的方式。Codex、Git 等工具均以 CLI 为主要交互方式。

## D

- **DeepSeek**：国产开源大语言模型系列，以高性价比和中文优化著称。详见 [[DeepSeek]]。
- **Dify**：开源 LLM 应用开发平台，提供可视化工作流编排、RAG 管道和 Agent 能力。详见 [[AI Agent 框架（Dify / Coze / Hermes / OpenClaw）]]。
- **Docker**：容器化部署引擎，将应用及依赖打包为轻量容器，实现"一次构建，到处运行"。详见 [[Docker 速查]]。

## F

- **Frontmatter**：Markdown 文件开头的 YAML 元数据块，用于存储页面的标题、类型、状态、标签、来源等结构化信息。详见 [[结构化笔记]]。

## G

- **Git**：分布式版本控制系统，本仓库使用 Git 追踪 Wiki 的每一次变更。详见 [[Git 版本化知识库]]。

## H

- **Hermes**：开源 AI Agent 框架，支持微信对接、NAS 部署、定时任务等。详见 [[AI Agent 框架（Dify / Coze / Hermes / OpenClaw）]]。

## I

- **iStoreOS**：带应用商店的 OpenWRT 优化固件，降低软路由使用门槛。详见 [[OpenWRT 与软路由]]。

## J

- **检索增强生成**：见 [[RAG]]。

## K

- **Codex**：OpenAI 开源的终端 AI 编程代理，支持文件读写、命令执行、MCP 集成。详见 [[Codex]]。
- **Coze**：字节跳动推出的 AI Bot 搭建平台，支持工作流、插件、知识库、多端发布。详见 [[AI Agent 框架（Dify / Coze / Hermes / OpenClaw）]]。

## L

- **LLM Wiki**：一种面向 AI Agent 维护的结构化知识编译系统。详见 [[LLM-Wiki]]。

## M

- **MCP（Model Context Protocol）**：Anthropic 提出的 AI 模型与外部工具间的标准化通信协议，被誉为"AI 应用的 USB-C 接口"。详见 [[MCP（Model Context Protocol）]]。
- **Mermaid**：基于 Markdown 的图表生成工具，支持流程图、时序图、类图、甘特图等。本 Wiki 使用 Mermaid 绘制知识图谱。
- **MkDocs**：基于 Python 的静态文档站生成器。本仓库使用 MkDocs Material 主题渲染 Wiki 页面。详见 `mkdocs.yml`。

## N

- **NAS（网络附加存储）**：24 小时运行的家庭/办公室服务器，集文件存储、媒体中心、Docker 应用、智能家居中枢于一身。详见 [[NAS 与自建服务]]。
- **n8n**：开源工作流自动化工具，支持 400+ 集成节点，可本地部署。

## O

- **Obsidian**：本地 Markdown 知识库工具，支持双向链接、图谱视图和丰富社区插件，是 LLM Wiki 的前端编辑工具之一。
- **OpenClaw**：开源 AI 助手框架，支持 WordPress 自动上货、多平台对接。详见 [[AI Agent 框架（Dify / Coze / Hermes / OpenClaw）]]。
- **OpenRouter**：多模型 API 聚合平台，统一计费，支持 ChatGPT、Claude、DeepSeek、Grok 等主流模型。
- **OpenWRT**：开源嵌入式 Linux 操作系统，可将普通路由器变为可编程网络网关。详见 [[OpenWRT 与软路由]]。

## P

- **Perplexity**：AI 搜索引擎，实时联网检索并标注来源，适合研究型查询。

## R

- **RAG（检索增强生成）**：Retrieval-Augmented Generation，通过从外部知识库检索相关文档片段来增强 LLM 回答质量的技术。详见 [[RAG]]。

## S

- **SEO（搜索引擎优化）**：Search Engine Optimization，通过技术手段和内容策略提升网站在搜索引擎中的自然排名。详见 [[SEO工具]]。
- **Semrush**：全能 SEO 平台，提供关键词研究、竞品分析、外链监控、内容优化。详见 [[SEO工具]]。

## T

- **TikTok 电商**：在 TikTok 平台上通过短视频、直播、小店进行跨境电商的模式。详见 [[TikTok 电商]]。

## W

- **WooCommerce**：WordPress 官方电商插件，将网站变为功能完整的在线商店。详见 [[WordPress]]。
- **WordPress**：全球最广泛的开源 CMS，占据约 43% 的网站份额，支持博客、企业站、电商站。详见 [[WordPress]]。

## X

- **向量数据库**：将数据以向量形式存储和检索的数据库，是 RAG 管道的核心组件。如 Pinecone、Chroma、Milvus。
- **双向链接**：一种笔记组织方式，在两个相关页面之间建立互相引用关系。详见 [[双向链接]]。
- **YAML**：YAML Ain't Markup Language，一种人类可读的数据序列化格式，本仓库用于 frontmatter 元数据声明。

## Y

- **亚马逊运营**：在 Amazon 平台进行选品、Listing 优化、广告投放、库存管理等电商运营活动。详见 [[亚马逊运营]]。

## Z

- **知识编译**：将原始信息经 AI 消化提炼后，转化为结构化的知识页面。详见 [[知识编译]]。
- **知识图谱**：以节点（概念/实体）和边（关系）组织的知识网络。本 Wiki 通过双向链接形成隐式知识图谱。
- **容器（Container）**：Docker 镜像的运行实例，轻量级虚拟化方案。详见 [[Docker 速查]]。
- **自动化工具（n8n / Zapier / Make）**：通过可视化流程编排连接不同应用，实现数据同步和任务自动化。详见 [[自动化工具对比（n8n / Zapier / Make / Dify / Coze）]]。
