# 周期维护提示词

请对中文 LLM Wiki 仓库进行一次周期维护。

## 步骤

1. **运行健康检查**：`python tools/wiki_lint.py --verbose`
2. **检查过期页面**：review 所有 status 为 `outdated` 的页面。
3. **补充术语表**：检查是否有新概念需要加入 `glossary.md`。
4. **更新路线图**：检查 `roadmap.md` 是否需要标记完成或添加新项。
5. **审查 log.md**：检查最近操作是否有待办项未完成。
6. **更新 changelog.md**：如有版本级变更。
7. **运行索引更新**：`python tools/update_index.py`
8. **提交变更**：`git add . && git commit -m "周期维护"`

## 输出

- 维护报告（记录到 `log.md`）
- 待办清单（需要人工处理的项目）

## 注意事项

- 只修明确的问题，不做过度的"优化"。
- 如有不确定的内容，标记而不强行修改。
- 保持 Git diff 清晰。
